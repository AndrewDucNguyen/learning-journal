## What an algorithm is
**Definition:** A set of step-by-step instructions for solvign a problem

Typically executed by computers, but humans also use algorithms in everyday life. Algorithm is not necssarily code; it's the logical procedure or recipe that a computer program or person could follow.

## Important
Algorithms aren't just about solving a problem, but also about how efficiently you solve it

You have to test algorithms on different kinds of inputs, including special or edge cases, to discover bugs

## Conclusion
Algorithms are just sets of instructions to solve problems

You can represent algorithms in pseudocode, which is not real code but looks code-like and preceisely describes the steps

Two big properties:
- Correctness: does it always produce the right answer
- Efficiency: How quickluy does it solve the problem

The process of designing algorithms:
- Start with a simple, obviously correct method
- Look for ways to make it faster or more efficient
- Test the changes and fix bugs when algorithms fail on certain input

Good algorithm is not just about getting an answer, its about getting the right answer reliable and doing it efficiently
