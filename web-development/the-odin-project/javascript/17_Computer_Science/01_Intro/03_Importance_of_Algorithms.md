## Notes
The main idea is that, initially, web development didn't need algorithm or it needed very little of it. Now because websites and webapps are driven by data, it is super important to make sure it is running efficiently and smoothly. 

When thousands or millions of users would do a serach or something, the website/webapp should be able to handle the large bandwidth of requests. This is where it is important for algorimths because it lets you figure out the most efficient way to handle large amounts of data.

In order to grow big, you have to support a lot of data searching, browsing, updating, and deleting. These operations have to be extremely efficient on the average case. The only way to address these issues is to use advanced data structures and algorithms.
