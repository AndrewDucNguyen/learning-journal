# Recursive Methods

## Intro
Recursion is a function calling itself

Used to take big problem and start breaking it down into smaller and smaller pieces (divide and conquer: D&C) and feeding the solutions back into the original function until an answer is achieved

    In computer science, divide and conquer (D&C) is an important algorithm design paradigm based on multi-branched recursion. A divide and conquer algorithm works by recursively breaking down a problem into two or more sub-problems of the same (or related) type, until these become simple enough to be solved directly. The solutions to the sub-problems are then combined to give a solution to the original problem.

There are right and wrong ways to use recursion. There could be some problems where breaking it down into smaller pieces will totally overwhelm the computer's memory
